# E-Commerce Sales Analysis Dashboard (Excel) 

This project presents a complete **end-to-end data analysis and dashboard solution built entirely in Microsoft Excel**, focusing on customer behavior, sales trends, and operational performance in an e-commerce business.


## Project Objective

The objective of this project is to:
- Clean and prepare raw e-commerce sales data
- Create new calculated columns using Excel formulas
- Build an interactive Excel dashboard with KPIs, trends, heatmaps, and maps
- Answer key business questions related to sales, customers, and delivery performance



## Tools Used

- **Microsoft Excel**
  - Data Cleaning
  - Formulas & Calculated Columns
  - Pivot Tables
  - Pivot Charts
  - Conditional Formatting (Heatmaps)
  - Map Visualizations
  - KPI Cards & Dashboards


## Dataset Overview

- **Dataset Type:** E-commerce transactional sales data  
- **File Format:** Excel / CSV  
- **Data Scope:** Orders, customers, products, shipping, and satisfaction details  


## Data Cleaning & Preparation

The raw dataset was cleaned and transformed using Excel techniques:
- Removed duplicates and handled missing values
- Standardized categorical values (e.g., gender)
- Corrected data types (dates, numeric fields)
- Ensured consistency across customer and order data


## New Columns Created (Using Excel Formulas)

To enhance analysis, the following calculated columns were created:

- **Days to Delivery** – Calculated using order date and delivery date  
- **Week Number (WeekNum)** – Used for weekly trend analysis  
- **Gender Value** – Standardized gender classification for analysis  
- Additional helper columns to support KPIs and dashboard visuals  


## Dashboard Overview

A **fully interactive Excel dashboard** was created using Pivot Tables and charts, focusing on KPIs, trends, and customer insights.

### Key KPIs Included
- Total Orders
- Total Sales
- Average Delivery Time
- Customer Satisfaction Score
- Average Quantity Purchased


## Business Questions Answered by the Dashboard

The dashboard is designed to answer the following key business questions:

- **Trend in the last 13 weeks**  
- **How do our customers like to buy?** (purchase behavior & channels)
- **How many items do customers buy?**  
- **Which products are most popular?**  
- **Overall gender split of customers**  
- **Where do our customers live?**  
- **How long do we take to ship orders?**  
- **How happy are our customers?**  

Each question is addressed through dedicated visuals and KPIs in the dashboard.


## Visualizations Used

- Line charts for **13-week sales trends**
- Bar and column charts for **product popularity**
- Donut charts for **gender split**
- KPI cards for quick performance overview
- **Heatmaps** to show relationships between key variables
- **Geographical maps** to highlight regions with the highest number of orders
- Slicers for interactive filtering (date, product, location, gender)


## Key Insights

- Clear weekly sales trends observed over the last 13 weeks
- Certain products consistently outperform others
- Customer purchase behavior varies by location and gender
- Delivery time has a direct impact on customer satisfaction
- Majority of orders are concentrated in specific regions
